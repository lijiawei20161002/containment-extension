# Main figures

`incidents/` contains the source-linked case illustrations and cross-case
analysis figures that motivate the [project story](../README.md).

Use the [dashboard](../dashboard/index.html) for feedback and evaluation-awareness
comparisons. Earlier optimization architectures, benchmark illustrations,
judge-reliability graphics, and alternate experiment figures are preserved in
[archive/figures/](../archive/figures/); presentations are in
[archive/slides/](../archive/slides/).

Incident figures are built by `scripts/draw_incident_figures.py`; cross-case
plots are built by `scripts/analyze_incident_library.py`. Their underlying case
records and evidence limits live in [incidents/](../incidents/README.md).
